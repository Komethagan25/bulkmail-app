# 📧 Bulk Mail Application (MERN Stack)

A full-stack Bulk Email Sending Application built using the MERN stack.
Users can send emails to multiple recipients with subject, message.

## Live Link 
         https://bulkmail-app-three.vercel.app

##  Tech Stack

### Frontend
- React.js
- Axios
- Tailwind CSS / CSS
- Vercel (Deployment)

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Brevo (Transactional Email API)
- Render (Deployment)

##  Features

- Send bulk emails
- Subject and message support
- MongoDB database integration
- Secure environment variables
- CORS configured for production
- Fully deployed (Frontend + Backend)
